</details>

<details>
<summary>Hint 3 — Akses milik staff lain</summary>

</details>

<summary>Hint 4 — Hash lama</summary>

Jika kamu menemukan password hash, identifikasi jenis hash-nya. Tidak semua aplikasi modern memakai bcrypt.

</details>

<details>
<summary>Hint 5 — Full chain</summary>

</details>
